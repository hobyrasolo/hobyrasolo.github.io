# Site académique bilingue — Hoby Nirina Rasoloarimanana

Site statique prêt pour GitHub Pages.

## Fichiers

- `index.html` : accueil, avec le contenu principal « À propos »
- `about.html` : profil détaillé avec photo
- `research.html` : thèse, productions, expérience et formation
- `cv.html` : affichage et téléchargement du CV
- `style.css` : identité blanche et verte, responsive
- `main.js` : langue FR/EN, menu mobile et retour en haut
- `brand.svg` : marque de navigation
- `profile_hoby.png` : portrait
- `hoby-nirina-rasoloarimanana-cv.pdf` : CV affiché et téléchargeable
- `hoby-nirina-rasoloarimanana-cv.tex` : source LaTeX du CV

## Mise en ligne

Copier tous les fichiers à la racine du dépôt GitHub Pages. Aucun outil de compilation n’est nécessaire pour le site.
